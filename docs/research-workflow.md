# Organize research sources and create Markdown notes

Prism Chat is the research side of Prism AI. Use it to organize projects, work with sources, ask questions, and create Markdown notes.

## Create a research project

1. Open Prism Chat.
2. Create a new project.
3. Add a project goal and supporting context.
4. Start conversations within that project.

Keeping research work organized by project makes it easier to separate topics, sources, and drafts.

## Work with sources

Prism Chat can collect article extracts and scholarly abstracts from supported sources, including Wikipedia, Crossref, and optional Tavily or OpenAlex sources.

You can:

- Ask research questions using a configured local or cloud model.
- Review source cards connected to responses.
- Open matching sources through clickable citation markers.
- Check whether a supporting quote appears in retrieved source text.

A quote match confirms that text appears in retrieved material. It does not establish that the source or broader claim is correct.

## Create Markdown notes

From a conversation or research session, you can:

- Create a Markdown document.
- Edit and save notes.
- Download the document.
- Export conversations, sources, and tasks as Markdown.

## Move from research to writing

When your notes and outline are ready, open Prism Studio to draft, revise, or compile a LaTeX document.

See [Write and compile LaTeX documents](latex-workflow.md).
