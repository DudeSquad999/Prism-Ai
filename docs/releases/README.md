# Prism AI releases

## Choose the right version

| Release | Product | Download guidance |
| --- | --- | --- |
| [v3.1.0](v3.1.0.md) | Windows research and LaTeX workspace: Prism Chat and Prism Studio | Current documented Windows release. Use the published EXE installer. |
| [v2.0.0](v2.0.0.md) | Earlier Windows Chat and Studio setup package | Archived. Prefer the latest Windows release for a new installation. |
| [v1.0.0](v1.0.0.md) | Educational PyTorch Transformer prototype | Historical prototype, not the current Windows applications. |

Check [GitHub Releases](https://github.com/DudeSquad999/Prism-Ai/releases) for the latest published build. Repository documentation changes do not rebuild or replace released applications.

GitHub's automatically generated source-code ZIP and tar archives are repository snapshots, not Windows installers. The complete packaged Windows application source is not included in this static-preview repository.

## Release-note standard

For future releases, record the exact asset filename, supported platform, version-specific changes, installation and upgrade steps, checksum, known limitations, and tests actually performed. Do not claim successful Windows installation, provider connectivity, performance improvements, migration compatibility, or code signing without evidence.

Keep published tags and historical binaries intact. Separate current browser-workspace documentation from claims about a released desktop binary.
