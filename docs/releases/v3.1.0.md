# Prism AI 3.1.0: Windows research and writing

Published October 13, 2026. These notes clarify the existing release; they do not announce a new build or certify additional testing.

## Download for Windows

Download [Prism-3.1.0.exe](https://github.com/DudeSquad999/Prism-Ai/releases/download/v3.1.0/Prism-3.1.0.exe) from the [v3.1.0 release](https://github.com/DudeSquad999/Prism-Ai/releases/tag/v3.1.0). Source-code ZIP and tar archives are not Windows installers.

```text

```

In PowerShell, from the folder containing the download:

```powershell
$expected = '36b261bff2efb42195aa137d50f38cd81c7901f8c9aa78bbb761b5fb4f5947c9'
$actual = (Get-FileHash -LiteralPath '.\Prism-3.1.0.exe' -Algorithm SHA256).Hash
if ($actual -ne $expected) {
    throw 'Checksum mismatch. Do not run the installer.'
}
'Checksum matches the published digest.'
```

The digest is reproduced from the published release notes, not newly calculated from the binary during this documentation update. A checksum comparison is not a malware scan or a code-signing verification.

## Included applications

- Prism Chat: research projects, conversations, source material, and Markdown notes.
- Prism Studio: LaTeX writing, review of proposed AI edits, references, and PDF workflows.

The original release notes do not provide a detailed comparison against v2.0.0. These capabilities are an overview, not a claim that every item was introduced in v3.1.0.

## Install and configure AI

1. Verify the downloaded installer, then run it on Windows.
2. Follow the [installation guide](../installation.md).
3. Configure Ollama with a downloaded local model, or supply your own key for a supported cloud provider. The release notes list Google Gemini, Anthropic, and OpenAI.
4. Configure and check Chat and Studio separately. Do not assume they share provider settings.
5. Use non-sensitive sample content for the first connection check. Chat's offline demo responses are not proof of live inference.

Exact Windows Ollama controls, a tested model, and application-specific connection evidence remain tracked in [issue #37](https://github.com/DudeSquad999/Prism-Ai/issues/37). See the [local-model guide](../local-models.md).

## Before upgrading

Keep backups of important projects and configuration. This documentation update does not establish in-place upgrade behavior, project-format compatibility, or a tested rollback procedure. Do not assume those workflows have been verified.

## Browser workspace is separate

The current [browser workspace](https://dudesquad999.github.io/Prism-Ai/) can connect directly to a local Ollama model, according to Main's current documentation. Without Ollama it uses labeled sample responses. It does not include live web search, citation verification, or document uploads. See the [browser workspace guide](../browser-demo.md).

This corrects the older release description's statement that the browser preview never connects to AI. Browser changes do not update the v3.1.0 Windows installer or establish desktop provider connectivity.

## Limitations and privacy

- Windows is the documented platform for this release.
- Local inference does not mean every feature works offline; initial downloads and research retrieval may require internet access.
- Content included in cloud requests is sent to the configured provider. API keys are not supplied.
- Generated answers, sources, and citations can be incomplete or incorrect. Verify important claims against original sources.
- Do not expose the applications to the public internet without appropriate authentication and security controls.
- This documentation update did not run the Windows installer, test providers, or rebuild binaries.

## Report a problem

Open a [GitHub issue](https://github.com/DudeSquad999/Prism-Ai/issues) with the version, affected application, Windows version, reproduction steps, expected and actual behavior, and sanitized errors. Remove API keys, private research, personal information, and private file paths.
