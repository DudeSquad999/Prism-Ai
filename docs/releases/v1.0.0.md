# Prism AI v1.0.0 historical release notes

> **Historical archive:** v1.0.0 was an educational PyTorch Transformer prototype. It is not the current Windows research and writing product, Prism Chat and Prism Studio.

- **Published release:** [Prism-Ai v1.0.0 - Research Chat](https://github.com/DudeSquad999/Prism-Ai/releases/tag/v1.0.0)
- **Original archive:** [PrismV1.0.0.zip](https://github.com/DudeSquad999/Prism-Ai/releases/download/v1.0.0/PrismV1.0.0.zip)
- **Archive SHA-256:** `920ee0ad7236907451e1c408b1004096f74d59aa60b21cdd2b5f7cfdd242628b`

## Added

- A small Transformer language model implemented in PyTorch without a dependency on a pretrained model or hosted inference API.
- Causal self-attention using a lower-triangular mask to prevent attention to future tokens.
- Multi-head attention, residual projections, dropout, feed-forward layers with GELU, and pre-LayerNorm Transformer blocks.
- A character-level tokenizer with vocabulary construction, encode/decode operations, and serializable tokenizer state.
- Autoregressive text generation with temperature scaling and top-k vocabulary filtering.
- Training and validation data splitting, AdamW optimization, cross-entropy loss, gradient clipping, and checkpoint save/resume support.
- Hardware selection that uses CUDA when available and falls back to CPU.
- Command-line training, text generation, and interactive terminal chat entry points.

## Quick start from the original archive

The original release targeted Python and PyTorch. These commands describe that historical prototype, not the current Windows applications.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pytest
python train.py --steps 2000
python chat.py
```

## Benchmark and compatibility note

The published v1.0.0 release notes did not include a reproducible performance benchmark suite or hardware-specific throughput results. No latency, tokens-per-second, or model-quality claims are added here. Model output quality depended on the training dataset, configuration, and training duration.
