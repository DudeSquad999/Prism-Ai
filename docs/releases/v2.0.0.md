# Prism AI 2.0.0: archived Windows setup

Published October 8, 2026. This is an archived Windows release containing Prism Chat and Prism Studio. For a new installation, use the [latest published release](https://github.com/DudeSquad999/Prism-Ai/releases/latest).

## Historical download

The package is named `PrismV2.0.0.zip`. Find it on the [v2.0.0 release page](https://github.com/DudeSquad999/Prism-Ai/releases/tag/v2.0.0). This package is distinct from GitHub's automatically generated source-code archives.

The historical instructions say to extract the ZIP, read `READ ME FIRST.txt`, and run `Install Prism.bat` from the extracted folder, not from inside the ZIP.

No independently verified v2.0.0 checksum is added by this documentation update.

## What the release documented

- Prism Chat: project conversations, research retrieval, source navigation, Markdown artifacts, tasks, and conversation export.
- Prism Studio: LaTeX editing, review of AI-proposed changes, BibTeX references, PDF compilation, snapshots, and project ZIP import/export.
- Combined Windows setup with provider configuration and application shortcuts.
- Provider options: Google Gemini, Ollama, Anthropic, and OpenAI. Cloud options require the user's own API key.

These are capabilities described in the original release notes, not new test results.

## Historical operating notes

The original release lists Chat at `http://127.0.0.1:8000` and Studio at `http://127.0.0.1:8001`, with application terminal windows kept open during use. Treat these as v2.0.0 instructions, not universal settings for later releases.

## Limitations

- The release describes Chat as single-user, without user accounts.
- Offline demo responses do not establish a live AI connection.
- Research retrieval uses article extracts and abstracts, not complete paper PDFs.
- Finding a quote in retrieved text does not prove the source or its claim is correct.
- Initial installation and TeX package downloads may require internet access.
- Cloud requests send included content to the configured provider.
- Do not expose these local applications to the public internet without appropriate authentication and security controls.

This documentation update did not install or test v2.0.0 and does not certify upgrade or rollback compatibility with v3.1.0. Keep backups before changing installations.
