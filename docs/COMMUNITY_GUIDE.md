# Community

Use the right place for your question:

- **Question or setup help:** [Discussions](https://github.com/DudeSquad999/Prism-Ai/discussions), if enabled.
- **Something is broken:** [Bug report](https://github.com/DudeSquad999/Prism-Ai/issues/new?template=bug_report.yml).
- **Feature idea:** [Feature request](https://github.com/DudeSquad999/Prism-Ai/issues/new?template=feature_request.yml).
- **Code or documentation change:** open a pull request.
- **Security concern:** follow [SECURITY.md](../SECURITY.md); don't post sensitive details publicly.

## Keep it useful

- Say whether you're using the browser demo, Prism Chat, or Prism Studio.
- Include the app version and steps to reproduce when relevant.
- Search for an existing thread before starting another.
- Be respectful and separate confirmed behavior from guesses or ideas.
- Never share API keys, credentials, private conversations, or unredacted logs.

## Suggested Discussions categories

If Discussions is enabled, start with just four categories:

- **Announcements** — release and project updates.
- **Q&A** — questions and setup help.
- **Ideas & feedback** — suggestions and discussion.
- **Show and tell** — examples and experiments.

You can add more later if people need them. Follow the [Code of Conduct](../CODE_OF_CONDUCT.md).
