# What the Prism AI browser demo includes

The browser demo is a static preview of the Prism AI interface. It is intended to help you see the general layout and workflow before installing the Windows applications.

## What it does

The demo:

- Shows example interface content.
- Demonstrates the general structure of the Prism AI workspace.
- Runs entirely in the browser.

## What it does not do

The demo:

- Does not connect to AI models.
- Does not send requests to cloud providers.
- Does not demonstrate the live Windows applications.
- Does not include your own research projects, sources, or documents.

## Try the real applications

To use live AI features, download the Windows release from the [latest release page](https://github.com/DudeSquad999/Prism-Ai/releases/latest).

Live AI features require a configured local model through Ollama or a configured cloud provider.
