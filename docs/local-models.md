# Use Prism AI with Ollama and local models

Prism AI can use a local model through Ollama. With this setup, model inference runs on your own machine.

## Before you start

- Install [Ollama](https://ollama.com/).
- Confirm that your computer has enough memory and storage for the model you want to use.
- Download a model supported by your hardware.

## Set up a local model

1. Install and start Ollama.
2. Download the model you want to use.
3. Open Prism AI.
4. Open the AI or provider settings.
5. Select Ollama.
6. Choose your configured local model.
7. Start a conversation in Prism Chat or open a document in Prism Studio.

## Performance considerations

Local-model performance varies based on:

- CPU, GPU, and available memory
- The model you select
- The size of the context or documents included in a request
- Other applications running on your computer

If responses are slow, try a smaller model or close memory-intensive applications.

## Privacy

When you use a local model through Ollama, model inference runs on your own machine. You are still responsible for the security of your device, installed software, API keys, and project files.

Do not put API keys, passwords, private research, or personal information in public GitHub issues, discussions, screenshots, or posts.
