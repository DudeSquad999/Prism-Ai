# Prism AI narrated product tour

This narrated sample tour uses supplied v7.1 interface screenshots. It is an illustrated walkthrough, not a recording of a running application. The latest published release may look different; consult the [release notes](../CHANGELOG.md) and [documentation](installation.md) for current information.

## 1. Prism AI

Welcome to Prism AI, a Windows workspace for research and writing. This narrated tour follows the supplied version 7.1 interface screenshots. The latest published release may look different, so check the release notes for current features.

## 2. Two apps, one workflow

Prism has two desktop apps. Prism Chat brings projects, conversations, research, and notes together. Prism Studio is for writing and revising LaTeX papers and presentations. Start in Chat to explore an idea, then move your outline into Studio when you are ready to write.

## 3. Start with a project

Projects give related conversations and research a shared home. The sample project shown here is clearly labeled as fictional and separate from your work. It is a safe way to explore the interface. Check the preview and release notes before relying on any feature in your installed version.

## 4. Ask, research, and draft

In Prism Chat, choose a mode for the task. Ask is for ordinary conversation. Research can search supported sources and show retrieved material. Documents is for questions about files you provide. Create helps draft content. Review responses and sources carefully. A citation or matching quote is not proof that a larger claim is correct.

## 5. Keep evidence reviewable

The Library brings project evidence and writing materials into one place. Review retrieved extracts and abstracts, follow citation markers back to source cards, and organize drafts and documents. The available research sources vary, and the retrieved material may not include a complete paper. Verify important claims with the original source.

## 6. Make Prism fit your work

My Prism and Teach Prism provide ways to shape preferences and guidance. For example, the writing-style screen analyzes a sample and lets you review a suggestion before saving it. Teaching items can have their own scope and priority. Read each screen carefully and approve only the changes you want.

## 7. Write and compile

Prism Studio is the LaTeX writing workspace. Draft papers or presentations, review proposed edits before applying them, work with references, and compile a PDF using Tectonic. AI suggestions and references can be wrong, so review changes and verify citations. PDF compilation also depends on a working TeX setup.

## 8. Choose how AI runs

You can configure a local model through Ollama or connect a supported cloud provider. With a local model, inference runs on your computer, though downloads and some research features may still need the internet. Cloud prompts containing your content go to the provider you configure. Review the provider terms, and never share API keys.

## 9. Your next steps

To get started, download the Windows installer from the latest Prism AI release, not the source-code archive. Follow the installation guide, configure a local model or cloud provider if you want live AI, and begin with a project. This tour uses supplied version 7.1 screenshots and is illustrative. The published release is version 3.1.0, so screens and features may differ. Check the changelog and documentation for the current release.
