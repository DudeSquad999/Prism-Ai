AI and privacy

Local models

When configured through Ollama, model inference runs on your own machine. Performance depends on your hardware and selected model.

Cloud providers

When configured with Google Gemini, Anthropic, or OpenAI, content included in the request is sent to that provider.

Your responsibility

Keep API keys private and verify important claims, citations, and AI-generated content.

Frequently asked questions

Does Prism AI run entirely offline?

Prism AI can use a local model through Ollama, but live AI features require a configured local model or cloud provider. Initial installation and first-time TeX package downloads may require internet access.

Does the browser demo use AI?

No. The browser demo is a static interface preview with fixed example content. It does not connect to AI models or demonstrate the live Windows applications.

Which platforms are supported?

The current release supports Windows. Prism Chat is for research and Markdown workflows; Prism Studio is for AI-assisted LaTeX and PDF workflows.

Can Prism AI verify facts?

No. Prism can help organize sources and check whether a quote appears in retrieved text, but matching a quote does not prove that a broader claim is true.

Is Prism AI free?

Prism AI is open source under the MIT License. Cloud AI providers may charge according to your own account and usage.
