Prism Studio

Browser demo

The browser demo is a static interface preview. It does not connect to AI models or run the Windows applications.

AI and privacy

Prism AI can use a local model or a cloud provider.

  • Local models: When configured through Ollama, model inference runs on your own machine.
  • Cloud providers: When configured with Google Gemini, Anthropic, or OpenAI, content included in the request is sent to that provider.
  • Your responsibility: Keep API keys private and verify important claims and citations.
