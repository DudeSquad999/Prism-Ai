# Write and compile LaTeX documents with Prism Studio

Prism Studio is the writing side of Prism AI. It is designed for AI-assisted LaTeX writing, reference workflows, and PDF compilation.

## Start a document

Prism Studio can start from:

- A paper template
- A blank document
- A Beamer presentation template

You can also import an existing project ZIP file, including Overleaf-compatible projects.

## Draft and revise

Use Prism Studio to:

- Write and revise papers, articles, and presentations.
- Request AI-proposed revisions.
- Review proposed changes before applying them.
- Apply, reject, or undo individual edits.
- Apply or reject an entire batch of proposed edits.

AI suggestions can be incorrect. Review every change before applying it to an important document.

## Work with references

Prism Studio can:

- Search related work through arXiv and Crossref.
- Retrieve ready-to-use BibTeX references.
- Check bibliography entries against Crossref and arXiv.

Always verify references before submitting academic or professional work.

## Compile a PDF

Prism Studio uses Tectonic for PDF compilation. LaTeX package downloads are handled automatically, though first-time downloads may require internet access.

If compilation fails, review the error output and request AI-assisted help identifying the issue. You remain responsible for checking the final document.
