# Security policy

## Reporting a vulnerability

Do not publish exploitable security details, credentials, API keys, private user data, or proof-of-concept payloads in a public issue or discussion.

Use GitHub's [private vulnerability reporting flow](https://github.com/DudeSquad999/Prism-Ai/security/advisories/new) if it is enabled for this repository. If that option is unavailable, contact the maintainer privately through a verified channel listed on their GitHub profile. Do not post secrets publicly to get attention.

## What to include

- A short description of the affected component and version.
- The impact you believe is possible.
- Minimal reproduction steps that do not access other people's data.
- Any mitigations you know of.

Do not test against other people's accounts, systems, or data. Do not include real credentials in reports.

## Supported versions

Prism AI is an early-stage project. No formal support window or guaranteed response time is promised. Include the exact release or commit so the maintainer can determine whether it is affected.
