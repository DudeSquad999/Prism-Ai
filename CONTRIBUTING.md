# Contributing to Prism AI

Thank you for wanting to improve Prism AI. The project is currently in its research, planning, and product-design phase, so thoughtful feedback is especially valuable.

## Ways to contribute

- Share a feature idea or product-use case.
- Report a documentation problem or unclear requirement.
- Improve research, writing, diagrams, or examples.
- Propose implementation work that aligns with the roadmap.
- Review ideas related to model comparison, privacy, safety, evaluation, or user experience.

## Before opening an issue

- Search existing issues to avoid duplicates.
- Read the README and ROADMAP to understand the current direction.
- Explain the problem, the proposed outcome, and why it matters.

## Pull requests

1. Start from an up-to-date default branch.
2. Keep each pull request focused on one change.
3. Explain what changed and why.
4. Update documentation when behavior, plans, or terminology change.
5. Do not include credentials, API keys, private prompts, or user data.

## Standards

- Use clear, respectful language.
- Prefer specific examples over vague claims.
- Flag uncertainty when describing AI-model behavior or limitations.
- Design with privacy, transparency, accessibility, and user control in mind.

## Questions

Open a feature request or discussion-style issue with enough context for others to respond constructively.
